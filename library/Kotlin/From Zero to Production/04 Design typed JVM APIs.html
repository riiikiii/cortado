Design the smallest useful interface

How can a feed of quotes become a feed of prices without the consumer knowing the feed implementation? Open Types.kt. A Source supplies a value on demand. A Sink accepts a value. The distinction matters to the compiler and to the programmer deciding which part owns a transformation.

A fun interface has one abstract method. Kotlin can turn a lambda into an instance when the expected interface is known. Source { Quote(...) } builds an object. Calling latest later runs the lambda. Likewise the map extension returns a new source that invokes the original source and then transforms the result on each read. Nothing in that signature promises caching. Add a counter to the original lambda and call latest twice to observe two reads.

Read fun <T, R> Source<T>.map(transform: (T) -> R): Source<R> from the receiver outwards. A caller has a Source of T and a function that consumes T and produces R. The result is a Source of R. The dot gives the operation member-call syntax. The compiler resolves extensions from the receiver's declared type. A member function with an applicable signature takes precedence. An extension cannot override the runtime behaviour of a class.

Read variance in the direction data crosses the boundary

A Source of Quote can stand in for a Source of Any. Every object it produces will satisfy the broader promise. The out annotation expresses covariance. A Sink of Any can stand in for a Sink of Ticks because it accepts every Ticks the caller could send it. This is contravariance, written in. Follow the assignment to priceLog in the example. Reversing its direction would let a caller send an arbitrary String to a sink that only understands Ticks.

A mutable container both accepts and returns values. If a MutableList of Quote could stand in for a MutableList of Any, someone could append a String to the original quote list. The compiler disallows that assignment. Use a read-only List for a publishing interface when the caller only needs values. Generic type arguments are generally erased on the JVM. An is List<*> check can establish that an object is a list. It cannot prove that every element is a Quote. Check the elements or validate the input during deserialisation.

Introduce units where confusion would be expensive

The value class in Types.kt makes a price distinct from an arbitrary Long in Kotlin source. Compared with typealias Ticks = Long, it gives a real compiler-enforced distinction. Depending on context the compiler may use the underlying representation or box the value, particularly through generic interfaces. Use it to prevent unit mistakes. Benchmark before relying on an allocation saving.

Interface delegation forwards methods to the supplied implementation. This override counts calls at the boundary. Calls an implementation makes internally to its own methods can bypass the wrapper. If you need one observation per external request, this is appropriate. If you need one per database query, instrument the database adapter. Kotlin classes and methods are final by default. Plain interface composition usually suffices for this kind of behaviour.

Scope functions and Java callers

Choose by the required return value first. Let and run return the lambda result. Also and apply return the original receiver. Let and also pass it as an argument. Run and apply give it the implicit receiver named this. Nested scopes with several implicit receivers make it easy to modify the wrong builder. Use a normal local name when it clarifies ownership.

A Java library with unknown nullability can expose a platform type, often displayed as String! in an IDE. Assigning it directly to String permits a runtime failure on a null value. Assign to String? at the boundary and validate once. Java exceptions do not become checked exceptions in Kotlin source. For a Kotlin API consumed by Java, @Throws can expose the checked-exception contract and @JvmOverloads can emit selected overloads for trailing defaulted parameters. Named arguments are a Kotlin caller facility and cannot generally be used with Java methods.

Run the standalone class quotes.Types using the Maven exec command from chapter one. Expect Ticks(value=10125). Now replace the string-transforming expression inside let with println. Its inferred result becomes Unit, or null when the receiver is absent. That small change demonstrates how a scope function can accidentally turn a value pipeline into a side effect.
