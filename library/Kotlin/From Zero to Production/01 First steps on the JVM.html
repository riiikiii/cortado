From a text file to a running program

What actually executes when a Kotlin function runs? In this course the Kotlin compiler emits JVM class files, Maven assembles the application, and a Java 21 runtime executes it. You can use familiar Java libraries, thread dumps and JVM profilers from the first day. Kotlin also targets other platforms. The JVM is the target throughout because our deliverable is a database-backed HTTP service.

Download the companion project below and unzip it into a working directory. All commands start beside pom.xml. Install a JDK 21 and Maven 3.9.x, or import that POM into IntelliJ IDEA and select JDK 21 as the project and Maven runner JDK. The first build needs network access. No database is needed for the first seven lessons. The build fixes Kotlin at 2.2.21 and Spring Boot at 3.5.16 for reproducibility. Select a supported, patched baseline and retest when adopting the project.

Expected application output is two lines, accepted=2 rejected=1 and {GILT=10130}. Maven adds its own build log around them. In IntelliJ the same entry point has a run icon beside its main function. The service has a different entry point. Running its jar now would start Spring and require a database.

Read Kotlin in execution order

Start at main. A package gives the declaration its qualified name. An object declares one shared instance. Here it groups a demonstration entry point and holds no changing state. @JvmStatic makes the method discoverable by a Java launcher. A top-level fun main() also works. The compiler gives a top-level function in Application.kt a JVM owner named ApplicationKt.

Read args: Array<String> as “args has type array of strings”. The type follows the name. Type inference gives lines the type List<String>. A val fixes a binding, while var permits reassignment. Kotlin checks both at compile time. Type inference does not give a variable a different type when another branch executes. Double quotes delimit strings. A dollar sign introduces interpolation, and braces let the interpolation contain a full expression.

A lambda is a function value written in braces. With one parameter you may refer to it as it. ifEmpty only calls its lambda when the command line supplies zero values. ::parseLine passes a reference to a function. Writing parseLine(line) instead would call the function immediately on one line. The collection operations accept executable behaviour as arguments, much like a C# LINQ selector or a Python callable.

Expressions, loops and numbers

Try the following independent example in a Kotlin scratch file in IntelliJ. A function with an expression body uses =. A block-bodied function returning a value declares its return type explicitly. Both predicates below return Boolean. The ranges have different boundaries.

1..3 includes 3. 0 until size stops before size. Numeric conversions are explicit at function boundaries. A decimal literal with an L suffix has type Long. Dividing two integers discards the fractional part before a subsequent conversion could preserve it. Using Double here is suitable for an illustrative mean. We store the actual price as an integer number of hundredths in a single agreed quote unit. Thus 10125 means 101.25. A market with a different tick convention needs a different contract. A sum can overflow a Long even when each individual observation is valid.

Change the input and locate a failure

Predict one rejection and a best price of 8. The parser accepts the second line only. Compare with a single argument of BAD,?. The list of arguments now has one item so the sample defaults never run. The program prints zero accepted and an empty map. This distinguishes “no input supplied” from “input supplied but invalid”.

Observation Where to look
Maven reports an unsupported class-file version Compare the Java version printed by Maven with the version printed by your shell.
Main class cannot be found on a clean checkout Run compile or verify before the standalone exec goal. Check the package and class name.
Build passes but a changed function seems to have no effect Recompile. A direct exec goal can run the classes already in target.

The project tree has three boundaries worth remembering. Domain.kt describes valid data. Walkthrough.kt is a caller. The POM declares how the source becomes runnable bytecode. You can change the caller without changing which quotes are valid.

Write the first feature yourself

Before touching Spring, create src/main/kotlin/quotes/PriceLabel.kt. Add the following file, compile, and run quotes.PriceLabelKt with the same exec goal. This is a separate optional exercise in the extracted project. The label translates internal ticks into the desk's agreed display scale.

Expect GBP 101.25 and EUR 0.07. A single-quoted character and a double-quoted string have distinct types. An argument with a default may be omitted. Named arguments let Kotlin callers make a unit choice visible. Top-level private limits access to this source file. Internal restricts a declaration to the compilation module, public is the default, and protected applies to class members and their subclasses. A file can contain more than one declaration without a wrapper class.

The function works with integer arithmetic because the service has fixed the scale at two places and accepts positive values only. If you later accept negative prices, integer division truncates towards zero and this formatting algorithm needs revisiting. If instruments have different scales, pass an instrument convention explicitly. A financial domain rule that is implicit in a display function can otherwise slip into storage or comparison logic.

Read the POM once. Dependencies provide libraries on the compile or runtime classpath. Plugins perform build work. The Kotlin plugin compiles the source directories in the compile and test-compile phases. Surefire discovers JUnit tests. Boot's repackage goal creates an executable archive with application classes and dependencies. An IDE run starts classes directly and can succeed even if the packaged entry point is wrong. Run the distributable artefact in the HTTP smoke test to cover that last boundary.
