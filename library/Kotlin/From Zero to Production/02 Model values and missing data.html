Move uncertainty to the boundary

Start with Domain.kt from the companion. A feed sends GILT,10125. A second feed sends GILT,?. A caller that receives an actual Quote should be able to use its price immediately. The decision about malformed text belongs where the text enters the application.

Follow the successful input. Splitting at the comma produces two fields. Trimming affects whitespace at their edges. toLongOrNull() parses a base-ten Long or returns null on malformed input or overflow. The Elvis expression ?: return null exits the enclosing function on that branch. In the following lines the compiler knows ticks has type Long. The regex must match the full symbol. Finally, the primary constructor assigns its properties and executes the init block. A valid Quote cannot be constructed with a zero price through this constructor.

There are two checks for an intentional reason. The feed parser makes a bad line an ordinary rejected value so one poor record does not abort a batch. The constructor defends all call sites, including copies and the HTTP adapter. If the rules evolve, move the shared predicates to domain functions and keep a test for each entry path. This parser is for a two-field feed. Quoted CSV, escaped commas and localisation require an actual format contract and parser.

Nullability as control flow

The question mark on a type includes the null value. On a member access it short-circuits when the receiver is null. The compiler can smart-cast a stable local after a check. An open property, custom getter or mutable value may change between reads. Capture the property once in a local if your logic needs the same observation twice. !! forces an exception if the value is absent. That discards the opportunity to translate a malformed feed message at the point where its meaning is known.

A nullable result collapses all failure reasons. If a caller must route “unrecognised symbol” and “bad price” differently, encode those cases as a sealed result. The Booking hierarchy already shows this pattern for a different decision. A caller matching a sealed interface in a when expression gets a compiler check when a new permitted outcome is introduced. An else branch would hide that maintenance signal.

What value equality buys the service

Structural equality dispatches to equals. Referential equality asks whether the JVM references point to the same instance. Data classes derive equals, hashCode, toString, components and copy from primary-constructor properties. A property added in the class body is omitted from these generated comparisons. In the persistence guide the existing database row is reconstructed as a fresh object. == makes replay detection work across that boundary. Identity comparison would mark a genuine replay as a conflict.

A copy is shallow. Put a MutableList in a data class and the original and its copy can observe the same later insertion. A read-only List reference can still point at a collection owned by another writer. Use immutable element types and establish ownership at construction when a value will become a cache key. Mutating a field used by hashCode after insertion can make an entry effectively unfindable in its hash bucket.

Choose the shape of an API

Shape Appropriate caller decision Example
Nullable return Continue or skip Feed preview suppresses unparseable lines.
Sealed outcomes A bounded set of different actions Created, Replay and Conflict map to different HTTP statuses.
Exception The operation cannot satisfy its declared contract Constructing a Quote with zero ticks violates its invariant.
Enum All alternatives have the same payload shape A fixed set of feed environments.

Try Quote("GILT", 1).copy(ticks = 0). The copy constructs a new instance, so the same init check throws IllegalArgumentException. Try parseLine("GILT,0") next. It returns null. The difference is observable and intentional. It lets the application treat routine input quality and an invalid object-construction attempt separately.

Construct objects with explicit ownership

In a primary constructor, val or var declares a property as well as a parameter. Without either keyword the parameter is available during construction but does not become a public property. The counter above exposes a getter and limits its setter to the class. Kotlin properties compile to JVM accessors in the usual case. A computed property can calculate on demand, and a custom accessor can refer to a backing field through the name field.

FeedSession.demo() calls a factory on the companion object. Each factory call constructs a separate FeedSession even though the companion itself has one instance. This session is deliberately single-owner. Its counter would need coordination if several threads shared it. The constructor of Quote creates a value suitable for equality comparison; the constructor of FeedSession creates an object whose identity and changing state matter.

Model a parsing outcome with a sealed hierarchy when callers need reasons. A when expression over that hierarchy can also bind subtype-specific fields with smart casts.

Add a third subtype such as IgnoredHeartbeat and recompile. The expression stops compiling until you decide how to describe it. That is the maintenance property we want later when a new booking outcome must acquire a deliberate HTTP status.
