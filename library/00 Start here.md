# Start here

Welcome to your Cortado library. Everything here is published from the `library/` folder of the GitHub repository, so it opens without signing in and keeps working offline once it has downloaded.

> [!tip] This is a placeholder
> Add your own lessons to `library/` in the repository, then delete this note.

## Adding lessons

1. Put Markdown notes (`.md`) or standalone HTML guides (`.html`) in `library/`. Keep a guide's images, stylesheets and scripts next to it, and link to them with relative paths.
2. Each top-level folder becomes a **collection** on the Library screen.
3. Number files to set the reading order: `01 Introduction.md`, `02 Basics.md`.
4. Commit and push to `main`. The site redeploys in about a minute, and Cortado downloads only the files that changed the next time it's opened.

## Writing notes

Notes can use wikilinks like `[[Another note]]`, code with syntax highlighting, tables, task lists, Mermaid diagrams and maths such as $e^{i\pi} + 1 = 0$.
