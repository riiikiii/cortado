# Cortado

An installable, offline-first learning library for the HTML guides and Markdown notes in this repo. It's built for the iPad mini, and works on any modern browser.

- **Publish notes from this repo:** anything in `library/` ships with the site as Cortado Notes and opens for everyone with no sign-in. Push a change and Cortado downloads just the new or changed files.
- **Works offline:** everything is stored on the device.
- **Learn in order:** folders and numbered files set the reading order, with next and previous lesson buttons, and a friendly coffee cup to greet you.
- **Track your learning:** reading progress, Mark complete & continue, next and previous lesson, and progress badges in the sidebar.
- **Comfortable reading:** Light, Sepia and Dark themes, adjustable text size, font and line width, an outline for every note, and a reading progress bar.
- **Full-text search** (⌘K) across every note and guide, with highlighted snippets.
- **Renders standalone HTML guides**, scripts included, with their relative assets and links between guides working.
- **Renders Markdown** with wikilinks, callouts, code highlighting with copy buttons, tables, tasks, footnotes, Mermaid and KaTeX.
- Tabs, keyboard shortcuts, and layouts for portrait and landscape.

See [SETUP.md](SETUP.md) to run it, add notes, deploy to GitHub Pages and install it on the iPad.
